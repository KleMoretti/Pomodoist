# Interface font

Noto Sans SC is bundled for consistent Simplified Chinese rendering offline.
The unmodified variable font and OFL license are from
[google/fonts](https://github.com/google/fonts/tree/main/ofl/notosanssc).
The `wght` axis supplies interface weights through Flutter's `FontWeight`.
`OFL.txt` is packaged with the app and registered in Flutter's license registry.
